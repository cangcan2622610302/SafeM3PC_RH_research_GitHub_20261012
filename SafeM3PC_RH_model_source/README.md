# Safe-M³PC-RH model and source data

This package contains the Safety-verified Model Predictive Control framework based on Masked trajectory Models and a Rolling Horizon (Safe-M³PC-RH) implementation and the source records used to construct the six railway cases.

Use Python 3.12. From this directory run:

```bash
python -m pip install -r requirements.txt
python -m pip install -e . --no-deps
python -m pytest tests -q
python scripts/rebuild_data.py
python scripts/run_public_scenario_study.py
python scripts/run_controlled_comparison.py
python scripts/run_controlled_comparison.py --study parameters
python scripts/run_c1_rolling_experiment.py
```

`src` contains the network model, candidate construction, learned/rule/random ranking, mathematical optimization, independent constraint validation, and rolling state updates. `scripts` contains numerical entry points. Gurobi support is optional and requires a suitable license; the default model uses SciPy/HiGHS.

`data/public_hsr/high-speed trains operation data.csv` contains the original 2,798 down-direction records for the six selected dates and 11 corridor stations. All source columns are retained, including actual arrival/departure times and delays. `data/processed` contains the reconstructed cases actually used by the model. `rebuild_data.py` checks that the included source records reproduce those cases. Train counts are 15, 25, 31, 33, 35, and 37.

Recovery stages and their transition parameters are research assumptions defined in the implementation. Recorded operations do not provide observed labels for those emergency recovery stages. The numerical implementation uses outcome-masked candidate ranking; dual-mask generation and beam search are not implemented. Learning weights are regenerated by the training code.

No figures, plotting code, manuscripts, revision versions, saved experimental results, logs, or installed dependencies are supplied. Python comments and docstrings are removed. Running the scripts generates new numerical results under `outputs`. The supplied source data have no redistribution license established from the local files; verify the original dataset terms before public release.
